# VIPTrue Toolbox

VIPTrue Toolbox is a command-line operations toolbox for VIPTrue infrastructure workflows.

This repository is now managed with a GitHub-first, stage-based, release-aware workflow.

## Current status

- Current version: `0.3.2`
- Default branch: `main`
- Current phase: `Stage 0 — Governance Bootstrap`

## Workflow

1. Create or select an issue.
2. Create a dedicated branch from `main`.
3. Keep changes limited and reviewable.
4. Open a Draft PR.
5. Run static checks and review the diff.
6. Merge only after explicit approval.
7. Tag and release only after explicit approval.

## Project files

- `PROJECT_STATE.md` keeps the current project state and one next exact step.
- `ROADMAP.md` keeps the staged development plan.
- `AGENTS.md` defines contributor and assistant instructions.
- `CHANGELOG.md` keeps release-aware history.

## Safety

Use placeholders in examples. Do not commit confidential values or real production details. Changes with real infrastructure impact require explicit approval and careful review.
